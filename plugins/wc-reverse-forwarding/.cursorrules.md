# Role & Context
You are a senior full-stack WordPress & WooCommerce developer.
We are developing a standalone WooCommerce extension plugin: `wc-reverse-forwarding` (Canada Reverse Logistics & Freight Forwarding).

# Architecture & Code Quality Guidelines
1. Modern PHP 8.1+ syntax, strictly following PSR-4 autoloading standards.
2. Namespace: `ReverseForwarding\`
3. Do NOT store forwarding packages inside `wp_posts` or `wp_postmeta`. Always use dedicated custom database tables (`wp_rf_packages`, `wp_rf_consolidations`).
4. Ensure WordPress security standards: nonce verification, data sanitization (`sanitize_text_field`), escaping output (`esc_html`, `esc_attr`), and capability checks (`manage_woocommerce`, `read`).
5. Keep methods short, decoupled, and single-responsibility.
6. When interacting with WooCommerce, use WC standard hooks, filters, and standard CRUD objects.
